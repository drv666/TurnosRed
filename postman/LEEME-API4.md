# Postman para la actividad 4

Importar turnos-med-api4.postman_collection.json y seleccionar No environment.
La colección TurnosMed API define baseUrl = http://localhost:3004. Todas sus 47 solicitudes usan {{baseUrl}}.

Probar primero GET /especialidades y después Run con todas las solicitudes en orden, una iteración. Las variables de IDs se completan durante la ejecución. Los casos negativos deben devolver el error previsto y mostrar pruebas aprobadas.

El contrato nuevo de Pacientes y Turnos está propuesto en pacientes-turnos.md y no se presenta como implementado.
